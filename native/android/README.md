# Lens for Android

Kotlin WebView shell. Package `com.sapplex.lens`, minSdk 26.

The gallery UI is the same Vite build as the website, copied into `app/src/main/assets/www/`. Case images and JSON still load from jsDelivr at runtime, so the device needs network access.

## Open in Android Studio

1. Install [Android Studio](https://developer.android.com/studio) (Koala / 2024.1 or newer).
2. **File → Open** and select this `native/android` folder (not the repo root).
3. Wait for Gradle sync. If the wrapper jar is missing, Android Studio will offer to generate it.
4. Pick an emulator (API 26+) or a USB-debuggable phone.
5. Click **Run**.

Command line, if the Android SDK is installed:

```bash
cd native/android
./gradlew :app:assembleDebug
```

The APK lands at `app/build/outputs/apk/debug/app-debug.apk`.

## Refresh the web bundle

From the repository root, after changing `src/`:

```bash
npm install
npm run native:prepare
```

Then rebuild the Android app.

## Notes

- Signing a Play Store AAB requires your own keystore. This tree ships unsigned debug defaults only.
- `local.properties` (SDK path) is generated by Android Studio and is gitignored.
